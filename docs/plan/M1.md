# M1: Core and CLI

**Goals.** DB schema and migrations, the service layer with events, the Fastify API with token auth and scoped agent tokens, every agent command in `botss-cli.md`, plan check with cycles and collisions.

**Design notes.** Pure logic in `packages/core` (plan, globs, permissions, guard, scheduler, phases, quota, stream). One writer: `ProjectService`. The CLI is a thin HTTP client that reads scratch files locally.

**Acceptance.** Unit tests for the DAG, collisions (conservative glob overlap), permissions, transitions, quota, and stream parsing. Agent commands exercised end to end through fake-claude runs.
