# Example idea: todo list with accounts

Paste this into the Idea screen to try Botss on something small.

---

I want a simple todo app for my family. Each person signs up with email and password and sees only their own todos. A todo has a title, an optional due date, and can be marked done. The main screen lists open todos first, newest due date first, with done items collapsed at the bottom. People should be able to edit and delete their own todos. It should work well on a phone.

Out of scope for now: sharing lists between people, reminders, and social login.
